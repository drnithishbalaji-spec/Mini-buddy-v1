Mini AI Bot

A tiny chatbot you run on your computer.
Pick its brain, then just talk to it.

✨ Gemini🧠 GPT

What it can do

💬
ChatAsk it anything, like talking to an AI friend.
🌐
WebsitesSay "website …" and it builds a page, saved as website.html.
🖼️
PicturesSay "picture …" and it draws it, saved as picture.png.
🎬
Video plansSay "video …" and it writes the plan, saved as video-plan.txt.

How to run it

1
Use a computer (Windows or Mac) — it doesn't run on a phone.
2
Install Python from python.org.
3
In a terminal, run: pip install requests
4
Get a free Gemini key at aistudio.google.com/apikey and paste it into GEMINI_API_KEY at the top of the file.
5
Run it: python mini_ai_bot.py — then just type!

Commands

ask <question> — chat with the AI
website <idea> — build a web page
picture <idea> — draw a picture
video <idea> — write a video plan
use gemini / use gpt — switch brains
help — show commands  •  quit — goodbye

🐙 Get the code
Download mini_ai_bot.py and README.txt from the GitHub repo, then follow the steps above.
